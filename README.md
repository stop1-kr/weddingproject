# 결혼 나이를 바꾸는 투자 프로젝트 (중3 · 5차시)

## 파일 구조
```
index.html        홈 (이름 입력, 차시 링크, 진행률, 기록 백업/복원)
lesson1.html      1차시 결혼하게 될 나이 계산하기  (완성)
lesson2.html      2차시 결혼 비용 버는 시간 줄이기 (완성)
lesson3~5.html    3~5차시 (준비 중 안내 페이지)
css/style.css     공통 스타일 (아이패드 터치 대응, 인쇄/PDF 대응)
js/store.js       자동 저장(localStorage), JSON 내보내기/불러오기, 진행률
js/calc.js        금액·나이 시뮬레이션 공통 함수 (월 복리, 물가 상승 반영)
js/jobs-data.js   직업 참고 데이터 (data/jobs.json 과 동일 내용)
data/jobs.json    직업 목록 (다른 도구에서 재사용할 때 사용)
```

## GitHub Pages 배포
1. 저장소 루트에 위 파일을 그대로 올립니다.
2. Settings → Pages → Branch: `main` / `(root)` → Save
3. `https://아이디.github.io/저장소명/` 으로 접속합니다. 모든 경로가 상대경로라 저장소 이름과 무관하게 동작합니다.
4. 아이패드 사파리에서 공유 → "홈 화면에 추가" 하면 앱처럼 사용할 수 있습니다.

## 데이터 관리 주의
- 학생 입력은 **그 기기의 브라우저(localStorage)** 에만 저장됩니다. 기기를 바꾸면 이어지지 않습니다.
- 차시 끝에 홈 화면의 `내 기록 내보내기(JSON)` 또는 `인쇄/PDF 저장`을 루틴으로 만들어 두세요.
- 2차시는 1차시 값을 자동으로 불러옵니다. 같은 기기에서 1차시를 먼저 진행해야 합니다.

## 계산 규칙 (2차시)
- 금액 단위는 모두 **만원**. 결혼 비용 4억 = 40000.
- 목표 금액 = 결혼 비용 × 내가 준비할 비율, 그리고 **매년 물가 상승률(기본 3.1%)만큼 커짐** (기준 나이 15세).
- 자산은 **월 복리**로 계산: 매달 `자산 × (1+r)^(1/12) + 월 저축액`.
- 결혼 가능 나이 = 자산이 그 시점 목표 금액을 처음 넘어서는 나이.
- AI 추천은 수익률을 **최대 10%** 로 제한하고, 3~10% 중 "필요한 월 저축액이 월급의 60% 이하"가 되는 가장 낮은 수익률을 고릅니다. 없으면 10%로 계산하고 경고를 함께 보여 줍니다.

## 수업 중 참고 (기본값으로 계산한 결과)
남학생 예시: 취직 32세 / 취직 전 저축 5,654만원 / 월급 290만원 / 결혼 비용 4억 / 내 비율 50% / 물가 3.1%
- 수익률 0% (저축만): 목표액이 물가로 계속 오르므로 **평생 모으기 어려움**
- 수익률 3%, 월 145만원: 54.7세 / 수익률 6%: 46.4세 / 수익률 9.2%: 43.0세
- 4단계 조건 조정: 지방(3억)+내 비율 30%+취직 30세 → **34.6세** (수익률 6%, 월 145만원)
→ "수익률만 올리는 것보다 조건을 함께 바꿔야 한다"는 결론이 나오도록 설계되어 있습니다.

## 3차시 이후 데이터 계획
GitHub Pages는 서버가 없어 API 키를 숨길 수 없고 CORS 문제도 생깁니다.
주식·금·부동산의 **연도별 지수 자료를 미리 JSON으로 저장소에 커밋**해 사용하는 방식을 권장합니다.

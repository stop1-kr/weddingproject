## GitHub Pages 배포
1. 저장소 루트에 위 파일을 그대로 올립니다.
2. Settings → Pages → Branch: `main` / `(root)` → Save
3. `https://아이디.github.io/저장소명/` 으로 접속합니다. 모든 경로가 상대경로라 저장소 이름과 무관하게 동작합니다.
4. 아이패드 사파리에서 공유 → "홈 화면에 추가" 하면 앱처럼 사용할 수 있습니다.

## 데이터 관리 주의

## 계산 규칙 (2차시)
- 4단계 "비상상황" 버튼 → "부모님께 도움을 받는다" 버튼이 나타남. 지원 금액(최대 15,000만원)을 넣으면 신랑·신부가 같은 금액을 받는 것으로 보고 **결혼 비용에서 2배**를 뺌. 금액을 다시 넣으면 앞서 뺀 금액은 되돌린 뒤 새로 계산하고, "1차시 값으로 되돌리기"를 누르면 지원이 취소됨.
- 금액 단위는 모두 **만원**. 결혼 비용 4억 = 40000.
- 목표 금액 = 결혼 비용 × 내가 준비할 비율, 그리고 **매년 물가 상승률(기본 3.1%)만큼 커짐** (기준 나이 15세).
- 자산은 **월 복리**로 계산: 매달 `자산 × (1+r)^(1/12) + 월 저축액`.
- 결혼 가능 나이 = 자산이 그 시점 목표 금액을 처음 넘어서는 나이.
- AI 추천은 수익률을 **최대 10%** 로 제한하고, 3~10% 중 "필요한 월 저축액이 월급의 60% 이하"가 되는 가장 낮은 수익률을 고릅니다. 없으면 10%로 계산하고 경고를 함께 보여 줍니다.

## 수업 중 참고 (기본값으로 계산한 결과)
남학생 예시: 취직 32세 / 취직 전 저축 5,654만원 / 월급 290만원 / 결혼 비용 4억 / 내 비율 50% / 물가 3.1%
- 수익률 0% (저축만): 목표액이 물가로 계속 오르므로 **평생 모으기 어려움**
- 수익률 3%, 월 145만원: 54.7세 / 수익률 6%: 46.4세 / 수익률 9.2%: 43.0세
- 4단계 조건 조정: 지방(3억)+내 비율 30%+취직 30세 → **34.6세** (수익률 6%, 월 145만원)
→ "수익률만 올리는 것보다 조건을 함께 바꿔야 한다"는 결론이 나오도록 설계되어 있습니다.

## 3차시 이후 데이터 계획
GitHub Pages는 서버가 없어 API 키를 숨길 수 없고 CORS 문제도 생깁니다.
주식·금·부동산의 **연도별 지수 자료를 미리 JSON으로 저장소에 커밋**해 사용하는 방식을 권장합니다.


## 3차시 주가 자료 만들기 (선생님이 한 번만)
3차시의 **시가총액 TOP10**과 **2020년 이후 월말 종가**는 공공데이터포털 「금융위원회_주식시세정보」 API로 만듭니다.
서비스키를 웹페이지에 넣으면 학생에게 노출되므로, **미리 JSON으로 만들어 저장소에 올리는 방식**을 씁니다.

1. https://www.data.go.kr 에서 「금융위원회_주식시세정보」를 검색해 **활용신청** 후 **일반 인증키(Decoding)** 를 복사합니다.
2. 방법 A (내 컴퓨터): `pip install requests` 후 저장소 폴더에서 `python tools/build_stocks.py --key 인증키`
3. 방법 B (GitHub에서): 저장소 Settings → Secrets and variables → Actions → New repository secret → 이름 `DATA_GO_KR_KEY`, 값에 인증키 → Actions 탭 → "주가 자료 갱신 (3차시)" → Run workflow
4. 만들어진 `data/stocks.json`, `js/stocks-data.js` 가 저장소에 올라가면 학생 화면에 자동 반영됩니다.
5. 학생이 고를 수 있는 회사를 늘리려면 `tools/extra_companies.txt` 에 종목명을 한 줄씩 추가하고 다시 실행합니다. (종목명은 증권사 앱 표기와 같아야 합니다.)
6. **상장 회사 전체**를 넣으려면 Run workflow 화면에서 `all` 을 체크하거나, 내 컴퓨터에서 `--all` 을 붙여 실행합니다.
   매달 마지막 거래일의 전 종목 시세를 받는 방식이라 호출은 약 300~400건이고, 자료 파일은 2~3MB 정도가 됩니다.
   우선주·스팩은 빠지고, 자료가 1년이 안 되는 새내기 상장사도 빠집니다. 학생은 5단계에서 회사 이름으로 검색해 고릅니다.

주의
- 가격은 **월말 종가**이며 액면분할·병합은 자동 보정(실행 화면에 보정 내역이 출력됩니다), **배당금은 미포함**입니다.
- 이 API는 2020-01 무렵부터 자료가 있습니다. 화면의 시작 연도(2020년)는 자료에서 자동으로 읽어 표시하고, 그보다 늦게 상장한 회사는 실제 분석 기간이 따로 표시됩니다.
- 시가총액 순위는 코스피·코스닥 보통주 기준(우선주 제외)입니다. 우선주도 넣으려면 `--include-preferred` 를 붙입니다.
- 화면 모양만 확인하려면 `lesson3.html?demo=1` (가상의 연습 자료, 실제 주가 아님).

## 3차시 계산 규칙
- 내가 얻어야 하는 수익률: 2차시 4단계에서 조정한 값(없으면 1차시 값)으로 `CALC.needRate` 계산. 2차시와 같은 규칙(월 복리, 물가 상승 반영).
- 최대 손실폭 = 고점 대비 가장 크게 떨어진 비율(월말 종가 기준).
- "끝까지 투자 성공" = 최대 손실폭이 학생이 정한 최대 손실 이하일 때.
- 아니라면: 내 한도에서 팔고 나왔을 때의 수익률을 보여 줌. 그때까지의 고점 × (1 − 내 최대 손실%) 가격에 판 것으로 계산하고, 처음 투자한 돈과 비교함.
- 평균 연이율 = 연평균 복리 수익률(CAGR). 비교는 "n%p 더 높습니다/낮습니다".


## 4차시 ETF 자료 만들기 (선택)
ETF 자료가 없어도 4차시는 동작합니다(학생이 회사를 골라 '나만의 ETF'를 만들어 비교). 실제 ETF도 비교하려면:
1. data.go.kr 에서 「금융위원회_증권상품시세정보」를 **따로 활용신청**합니다. (인증키는 주식과 같은 것을 씀)
2. `tools/etf_list.txt` 에 ETF 이름을 적습니다. (증권사 앱 표기와 똑같이, 띄어쓰기 포함)
3. Actions → Run workflow → `kind` 에서 **ETF** 를 고르고 실행합니다. → `data/etf.json`, `js/etf-data.js` 생성
- `KODEX 200` 과 `KODEX 레버리지` 가 모두 있으면 3단계에 실제 레버리지 비교 그래프가 나타납니다.
- 이름이 틀리면 실행 기록에 `[건너뜀]` 과 비슷한 이름이 나옵니다.

## 4차시 계산 규칙
- 나만의 ETF = 고른 종목에 처음 같은 금액씩 넣고 계속 들고 있는 것으로 계산. 비교는 모든 종목에 자료가 있는 공통 기간만 사용.
- 1단계 분야별 비교 : `lesson4.html` 의 `SECTORS` 목록(분야별 회사 이름)으로 그릇을 만듭니다. 처음 보여 줄 분야는 자동으로 고르며
  (가장 좋은 회사 +400% 이하, 가장 나쁜 회사 −60% 이상, 그릇이 평균보다 덜 떨어진 분야 중 차이가 가장 큰 것), 고정하려면 `DEMO_DEFAULT='자동차'` 처럼 적습니다.
- 2단계 미국·한국 비교 : 달러 가격 × 그 달 말 원/달러 환율 = 원화 가격. 원화 수익률 = (1+달러 수익률)×(1+환율 변화)−1.
- 3단계 레버리지 : 매일 '그날 주가 변화 × 배수'만큼 움직이고(−100% 아래로는 0원), 결과를 '일반 투자 수익률 × 배수'와 비교해 설명합니다.
- 5단계 : 2020-01에 '처음 넣을 돈', 그 뒤 매달 '매달 넣을 돈'을 정한 비율대로 나눠 사고 끝까지 들고 있음(비율 조정 없음).
  예금·적금은 연 3% 월 복리, 해외 상품은 그 달 환율로 원화 환산. '1년 평균 수익률'은 매달 넣은 돈까지 고려한 수익률(IRR).
  최대 손실폭은 매달 넣은 돈의 영향을 뺀 투자 성과 기준. 이 수익률로 결혼 나이를 계산하고, 10%를 넘으면 10%로 계산한 나이도 함께 보여 줍니다.
- 5단계 결과 수익률은 5차시 게임의 '4차시 내 투자 비율' 카드에 쓰이며, 게임에서는 최대 10%까지만 씁니다.

## 5차시 인생게임
- 성별 선택 → 15세부터 갈림길 13~14개(카드 3장 중 선택, 일부는 룰렛) → "나는 ○세에 결혼했습니다".
- 계산은 2차시와 같은 규칙(월 복리, 물가 3.1%, 내 비율 50%). 결혼 비용 = 지역 비용 × 결혼식 배수 − 부모님 지원 × 2.
- 금액·확률은 `lesson5.html` 의 `EV`(갈림길)와 `FATE`(운명의 카드) 목록에서 바꿀 수 있습니다.

## 4차시 미국 주식·환율 자료 만들기 (선택)
야후 파이낸스(yfinance)를 써서 **API 키 없이** 만듭니다.
1. (선택) `tools/us_list.txt` 에 넣고 싶은 종목을 적습니다. 미국 시가총액 TOP10은 자동으로 들어갑니다.
2. Actions → Run workflow → `kind` 에서 **미국 주식·환율** 을 고르고 실행합니다. → `data/us.json`, `js/us-data.js` 생성
- 야후는 공식 API가 아니라 가끔 막힙니다. 실패하면 몇 분 뒤 다시 실행하세요. 환율은 야후가 안 되면 FRED(미국 연방준비제도) 자료로 받습니다.
- 가격은 액면분할 반영 종가(배당 미포함), 환율은 월말 원/달러입니다.
